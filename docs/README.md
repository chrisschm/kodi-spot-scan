## User documentation

There's no separate user handbook yet — for now, the root [`README.md`](../README.md) covers
what there is. A wiki (bilingual, like other projects from this maintainer) will start once
there's an actual first working version and real usage questions to answer, rather than
speculative documentation ahead of the tool itself.
